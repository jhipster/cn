## 包容性

与所有 JHipster 项目一样，JHipster 图像资源项目遵循 [JHipster 行为准则](https://github.com/jhipster/generator-jhipster/blob/main/CODE_OF_CONDUCT.md)。我们的目标之一是拥有包容性的图像资源：目前 "JHipster 家族" 有几个成员，但想法是这个家族会成长，拥有许多不同的成员，正如我们行为准则中所表达的那样。如果您想帮助项目，您可以作为艺术家参与（所有图像的源文件都可以在 [github 仓库](https://github.com/jhipster/jhipster-artwork) 中获得）或作为赞助商（这样我们可以付费给艺术家来创建这些新图像）。

所有图像都由 [Audrey Neveu](https://x.com/Audrey_Neveu) 验证，她因参与 [Devoxx4Kids](http://www.devoxx4kids.org/) 和 [Duchess France](https://www.duchess-france.org/) 而在 Java 社区中享有盛名。


## 标志和图像使用

所有标志和图像都可在 [Apache 2 许可证](pathname:///LICENSE.txt) 下使用，并属于 JHipster 项目。
