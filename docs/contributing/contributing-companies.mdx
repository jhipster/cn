## 对 JHipster 做出贡献的公司

* [Microsoft](https://www.microsoft.com/)，为 [@juliendubois](https://x.com/juliendubois) 提供时间和硬件来改进项目。
* [Okta](https://developer.okta.com/) 为 [@mraible](https://x.com/mraible) 提供了时间和硬件来改进项目。他们还贡献了 [OIDC 支持](/security/#oauth-20-and-openid-connect)和 [Ionic 蓝图](/modules/marketplace/details/generator-jhipster-ionic/)。
* [Google](https://google.com) 贡献了 [Kubernetes 子生成器](/kubernetes/)。它由 [Ray Tsang](https://x.com/saturnism) 维护。
* [Heroku](https://www.heroku.com/) 贡献了 [Heroku 子生成器](/heroku/)。它由 [Joe Kutner](https://x.com/codefinger) 维护。
* [CloudCaptain](https://cloudcaptain.sh/) 为 JHipster 添加了[特定支持](/cloudcaptain/)。它由 [Axel Fontaine](https://x.com/axelfontaine) 维护。
* [Software AG](http://www.softwareag.com/)，赞助 Ehcache，为我们大大改善 Ehcache 支持做出了贡献。
* [Hazelcast](https://hazelcast.com/) 为我们大大改善 Hazelcast 支持做出了贡献。
* [Liquibase](http://www.liquibase.com/) 一直帮助我们并为我们的 Liquibase 支持修正错误。
* [Redhat](https://www.redhat.com/en) 贡献了 Openshift 子生成器和 Infinispan 支持。
* [JFrog](https://jfrog.com/) 为我们提供了免费的 Artifactory 实例，用于我们的构建和发布。

## 帮助开发 JHipster 的公司

这些公司帮助我们开发 JHipster

* [Google](https://google.com)，自 2016 年以来向项目提供了价值 7,000 美元的“Google 云积分”。
* Pivotal，在他们的 [Pivotal Web Services](http://run.pivotal.io/) 云上给我们免费积分。
* [ElephantSQL](http://www.elephantsql.com/)，给我们提供了几个他们的“Pretty Panda” Postgresql 数据库。
* YourKit, LLC，给我们提供 [YourKit Java 分析器](http://www.yourkit.com/java/profiler/index.jsp)的免费许可证。
* EJ Technologies，给我们提供 [JProfiler Java 分析器](http://www.ej-technologies.com/products/jprofiler/overview.html)的免费许可证。

## 对 JHipster 做出贡献的项目和社区

JHipster 与其他 OSS 社区密切合作，经常为项目贡献代码、建议和评论。重要贡献来自：

* [Webpack](https://webpack.github.io/)，JHipster 用于 Angular 和 React 支持的模块打包器。
* [Gradle](https://gradle.org/)，JHipster 支持的构建工具之一。
* [Angular](https://angular.io/)。
* [UI Router](https://ui-router.github.io/)，在 JHipster 4 之前使用的 Angular 路由器。
