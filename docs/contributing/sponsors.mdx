JHipster 使用 [Open Collective](https://opencollective.com/generator-jhipster) 来筹集资金。这些资金用于以透明的方式承担项目费用（如运行此网站）（[参见 Open Collective 文档](https://opencollective.com/how-it-works)），您的捐赠将帮助项目持续发展并成功成长。

请访问我们的 [Open Collective 页面](https://opencollective.com/generator-jhipster) 成为支持者或赞助商。

## 免责声明

这是一项捐赠。不期望任何商品或服务作为回报。出于这些目的的任何退款请求都将被拒绝。

我们是一个法国非营利组织，如我们的[章程](/association/)中所述，我们对商业伙伴关系不感兴趣。

支持者每月向项目捐赠 2 美元。

## 项目如何使用这些资金？

正如您在 [Open Collective 文档](https://docs.opencollective.com) 中所读到的，您的资金使用方式将是公开和完全透明的。

任何人都可以提交费用申请。如果费用对社区发展有意义，核心贡献者将把它"合并"到我们开放集体的账本中，提交费用的人将得到报销。

资金将首先用于支付直接项目成本：

- [Bug 悬赏](/bug-bounties)
- 网站托管
- 开发工具
- 法律保护

然后，资金将用于：

- 支付项目周边产品
- 支付聚会费用
- 支付开发者聚会费用：核心团队会议的差旅和餐费

## 帮助！我是赞助商，但我的徽标没有出现！

对于每个赞助级别，我们使用 Open Collective API 在我们的主页上自动显示赞助商。如果您的徽标没有出现：

- 检查您是否选择了正确的赞助级别。这需要是上面列出的级别之一，而不是自定义贡献。
- 检查您的 Open Collective 个人资料以确保您的徽标已上传：这是我们用来在主页上自动显示您徽标的内容。
- 等待几分钟：Open Collective API 被缓存，因此您的徽标可能需要几分钟才能出现。

如果这些步骤不起作用，请联系 Open Collective 支持，因为我们无法控制他们的 API。他们可能有需要修复的错误或技术问题。
