JHipster 有很多[贡献者](https://github.com/jhipster/generator-jhipster/graphs/contributors)，我们尽最大努力帮助人们贡献！我们很乐意您加入！


## 行为准则

在您贡献之前，请阅读我们的[行为准则](https://github.com/jhipster/generator-jhipster/blob/main/CODE_OF_CONDUCT.md)。


## 寻求帮助

作为项目中的任何人，您可以使用我们在[帮助页面](/help)上列出的常用支持渠道寻求帮助。

无论您做什么，团队都将尽最大努力通过以下方式帮助您：

- 评论您的问题单
- 审查您的 Pull Request


## 如何贡献

我们的[贡献指南](https://github.com/jhipster/generator-jhipster/blob/main/CONTRIBUTING.md)应该给您所有的指针，让您开始并做您的第一个 Pull Request。
