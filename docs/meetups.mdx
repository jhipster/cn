我们目前正在世界各地创建 JHipster 聚会！

- 如果您想创建自己的聚会，请在[此网页](https://github.com/jhipster/jhipster.github.io/blob/main/pages/meetups.md)上进行 Pull Request，直接添加您的聚会。
- 聚会没有规则：您可以在想要的时候安排它们，在想要的地方举办，邀请您想要邀请的人。
- JHipster 团队将尽最大努力支持您：我们会在 Twitter 上转发您，将您的活动放在我们的主页上等。
