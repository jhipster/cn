MongoDB 是在生成应用程序时可以选择的支持数据库之一。

当选择 MongoDB 时：

* 将使用 Spring Data MongoDB 来访问数据库。这非常接近 Spring Data JPA，这就是为什么 MongoDB 支持非常接近（默认）JPA 支持的原因
* 使用 [Mongock](https://www.mongock.io) 而不是 [Liquibase](http://www.liquibase.org/) 来管理数据库更改
* 使用 [de.flapdoodle.embed.mongo](https://github.com/flapdoodle-oss/de.flapdoodle.embed.mongo) 来运行内存版本的数据库以运行单元测试。
