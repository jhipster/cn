## 功能

[Kafka](http://kafka.apache.org/) 是一个流行的发布-订阅消息系统。JHipster 对 Kafka 有可选支持，它将：

- 使用 JHipster 配置 [Kafka 客户端](https://docs.confluent.io/5.3.1/clients/consumer.html#java-client)。
- 在 `application-*.yml` 中添加必要的配置
- 生成一个 Docker Compose 配置文件，因此可以通过输入以下命令使用 Kafka：
  ```shell
  docker-compose -f src/main/docker/kafka.yml up -d
  ```


## 前提条件

生成一个新应用程序，并确保在提示您想使用的技术时选择 `Asynchronous messages using Apache Kafka`。将生成一个 Docker Compose 配置文件，您可以使用以下命令启动 Kafka：

```shell
docker-compose -f src/main/docker/kafka.yml up -d
```


## 消费者和生产者

一个消费者（`<appName>KafkaConsumer` 类）正在运行，可以根据您的需要进行调整。

一个生产者（`<appName>KafkaProducer` 类）也可用，可以通过 REST 端点（`<appName>KafkaResource` 类）调用。


## 运行应用程序

在 `SecurityConfiguration.java` 中允许访问端点：

```java
.antMatchers("/api/<appName>-kafka/publish").permitAll()
```

如果您调用端点 `http://localhost:8080/api/<appName>-kafka/publish?message=...`，您应该会看到消息被记录到控制台。
