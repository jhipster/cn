WebSockets 对于建立非常动态的应用程序非常有用，在其中数据在服务器和其客户端之间近乎实时地共享。

JHipster 目前使用 Spring WebSockets 作为其实现，因此您可以在 [Spring WebSockets 网站](http://docs.spring.io/spring/docs/current/spring-framework-reference/html/websocket.html)上找到有关此功能的更多信息。

此选项有一些限制：

- 默认情况下，我们使用 Spring Websockets 提供的调度程序，这是一个内存实现。如果您想使用多个服务器，它将无法扩展。如果您想这样做，请查看 [Spring WebSockets 文档](http://docs.spring.io/spring/docs/current/spring-framework-reference/html/websocket.html)，它解释了如何配置外部代理。


## "Tracker" 示例

JHipster 开箱即用地提供了一个 "tracker" 示例。位于 `admin` 菜单中，它将跟踪其他用户的行为：您将看到他们的登录名和 IP，以及他们当前正在查看的页面。

- 这作为一个示例提供，以便您可以开始使用 WebSockets，而不是作为 "生产就绪" 的用户跟踪器，但它工作得相当好。
- 它将向您展示如何将 WebSockets 与 Spring Security 集成，这是一个相当复杂的主题
- 这能够工作是因为 JHipster 是一个单页 Web 应用程序，因此 WebSockets 连接不会在各页面之间重新初始化：这是您获得 JHipster 架构大好处之一的地方
