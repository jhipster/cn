## 功能

[Pulsar](http://pulsar.apache.org/) 是一个流行的发布-订阅消息系统，支持流式和队列用例。JHipster 对 Pulsar 有可选支持，它将：

- 使用 JHipster 配置 [Pulsar 客户端](https://pulsar.apache.org/docs/2.11.x/client-libraries-java/)。
- 生成一个 Docker Compose 配置文件，因此可以通过输入 `docker-compose -f src/main/docker/pulsar.yml up -d` 使用 Pulsar。
- 使用 [Spring Cloud Stream](https://docs.spring.io/spring-cloud-stream/docs/current/reference/html/) Pulsar 绑定器和 [Testcontainers](https://www.testcontainers.org/) 生成集成测试。


## 前提条件

生成一个新应用程序，并确保在提示您想使用的技术时选择 `Asynchronous messages using Apache Pulsar`。将生成一个 Docker Compose 配置文件，您可以使用以下命令启动 Pulsar：

```shell
docker-compose -f src/main/docker/pulsar.yml up -d
```


## 用法

查看 [Spring for Apache Pulsar 文档](https://docs.spring.io/spring-pulsar/docs/current/reference/html/)（优先使用在您应用程序的 README.md 中生成的版本化 pulsar 文档链接）以了解如何在 JHipster 中使用 Pulsar。
有几种从最低到最高抽象级别与 Pulsar 交互的方法：
* 分别从 PulsarProducerFactory/PulsarConsumerFactory/PulsarReaderFactory 生成 Producer/Consumer/Reader
* 注入 PulsarTemplate 并创建 PulsarListener beans
* 在 `application.yml` 中配置 Spring Cloud Streams 绑定器和 Supplier/Consumer/Function beans（请参阅生成的测试示例）。
