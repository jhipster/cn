**公测版**

[Neo4j](https://neo4j.com/) 是在生成应用程序时可以选择的支持数据库之一。

当选择 Neo4j 时：

* 将使用 [Spring Data Neo4j/RX](https://neo4j.github.io/sdn-rx) 来访问数据库。这非常接近 Spring Data JPA，这就是为什么 Neo4j 支持非常接近（默认）JPA 支持的原因。
* 使用 [Neo4j Migrations](https://github.com/michael-simons/neo4j-migrations) 而不是 [Liquibase](http://www.liquibase.org/) 来管理数据库更改。
* 使用 [Neo4j Testcontainers](https://www.testcontainers.org/modules/databases/neo4j/) 来启动容器化版本的数据库以运行单元测试。
