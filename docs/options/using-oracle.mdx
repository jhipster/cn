在使用 JPA 时，您可以选择使用 Oracle 数据库。

_此选项仅支持 Oracle 12cR1 及以上版本（例如 19c、18c 和 12cR2）。_

在 JHipster 中使用 Oracle 时，根据 Oracle 数据库版本，将适用以下限制。

对于版本 19c、18c 和 12cR2：
- 实体名称不能超过 124 个字符，这是由于 Oracle 对对象名称的 128 个字符限制，我们保留 4 个字符来为生成的表生成主键序列。
- 实体字段名称不能超过 128 个字符。
- 在做关系时，外键名称不能超过 128 个字符，所以如果它们太长，将被截断。
- 在做多对多关系时，连接表名称将遵循 JPA 规范（形式为 "firstTable_secondTable"）：如果它超过 128 个字符，将被截断。

对于版本 12cR1：
- 实体名称不能超过 26 个字符，这是由于 Oracle 对对象名称的 30 个字符限制，我们保留 4 个字符来为生成的表生成主键序列。
- 实体字段名称不能超过 30 个字符。
- 在做关系时，外键名称不能超过 30 个字符，所以如果它们太长，将被截断。
- 在做多对多关系时，连接表名称将遵循 JPA 规范（形式为 "firstTable_secondTable"）：如果它超过 30 个字符，将被截断。

- Oracle 保留关键字不能用作实体名称或字段名称。

- Oracle 数据库 19c（EE、SE2、单实例和 RAC）Docker 镜像可以在这里找到：https://container-registry.oracle.com
- Oracle 数据库 19c Docker 构建文件可以在这里找到：https://github.com/oracle/docker-images/tree/master/OracleDatabase


请注意，强烈建议使用版本 19c，因为它具有长期支持（于 2027 年结束）。
