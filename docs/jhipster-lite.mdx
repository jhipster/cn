## 什么是 JHipster Lite？

就像 JHipster 一样，**JHipster Lite ⚡** 将帮助您启动项目，专注于逐步生成您需要的内容。

关于该解决方案的一些细节：
- 生成的代码使用[六角架构]
- 技术代码与您的业务代码分离
- 您只会生成您想要的代码，没有额外的未使用代码
- 尽可能最好的质量：💯% 代码覆盖率，0 代码异味，无重复 😎
- 这个生成器是一个使用 Java (Spring Boot) 和 Vue.js 的 Web 应用程序
