## 官方支持的蓝图

JHipster 团队维护着几个官方蓝图。这些蓝图有两个主要目标：

* 使用不同的语言和/或支持为 JHipster 增强新功能
* 演示如何修改主生成器行为以满足任何人的需求

下面的蓝图按照它们在 GitHub 上的星数排序。


## Kotlin

Kotlin 蓝图用 Kotlin 替换了大部分 Java 后端代码。源代码和文档可以在 [jhipster-kotlin](https://github.com/jhipster/jhipster-kotlin) 仓库中找到。

- 代码和文档：[jhipster/jhipster-kotlin](https://github.com/jhipster/jhipster-kotlin)
- GitHub ⭐️：446
- 负责人：[Sendil Kumar](https://github.com/sendilkumarn)


## .NET Core

.NET Core 蓝图是离开 Java 环境并加入 .NET 世界的首次尝试。

- 代码和文档：[jhipster/jhipster-dotnetcore](https://github.com/jhipster/jhipster-dotnetcore)
- GitHub ⭐️：307
- 负责人：[Nicolas Raymond](https://github.com/nicolas63)


## React Native

React Native 蓝图使用 React Native 创建客户端应用程序。

- 代码和文档：[jhipster/generator-jhipster-react-native](https://github.com/jhipster/generator-jhipster-react-native)
- GitHub ⭐️：260
- 负责人：[Jon Ruddell](https://github.com/ruddell)


## Node.js

Node.js 蓝图用 NestJS Node 框架替换服务器端 Java 代码。

- 代码和文档：[jhipster/generator-jhipster-nodejs](https://github.com/jhipster/generator-jhipster-nodejs)
- GitHub ⭐️：251
- 负责人：[Angelo Manganiello](https://github.com/amanganiello90)


## Ionic

Ionic 蓝图使用 Ionic 创建客户端应用程序。

- 代码和文档：[jhipster/generator-jhipster-ionic](https://github.com/jhipster/generator-jhipster-ionic)
- GitHub ⭐️：188
- 负责人：[Matt Raible](https://github.com/mraible)


## Quarkus

Quarkus 蓝图部分由 JHipster 赞助商 [Entando](https://www.entando.com/) 支持，由 JHipster 社区驱动，提供[超音速、亚原子 Java 后端](https://quarkus.io/)。

- 代码和文档：[jhipster/generator-jhipster-quarkus](https://github.com/jhipster/generator-jhipster-quarkus)
- GitHub ⭐️：136
- 负责人：[Matt Raible](https://github.com/mraible)


## Entity Audit

Entity Audit 蓝图集成 Javers 进行实体审计。

- 代码和文档：[hipster-labs/generator-jhipster-entity-audit](https://github.com/hipster-labs/generator-jhipster-entity-audit)
- GitHub ⭐️：131
- 负责人：[Marcelo Shima](https://github.com/mshima)


## Micronaut

Micronaut 蓝图由 [Micronaut 团队](https://github.com/jhipster/generator-jhipster-micronaut/graphs/contributors)本身的成员支持和驱动。
它用 [Micronaut](https://micronaut.io/) 应用程序替换所有服务器端代码。

- 代码和文档：[jhipster/generator-jhipster-micronaut](https://github.com/jhipster/generator-jhipster-micronaut)
- GitHub ⭐️：98
- 负责人：[Frederik Hahne](https://github.com/atomfrede)


## Svelte

Svelte 蓝图用 SvelteKit 框架替换客户端代码。

- 代码和文档：[jhipster/generator-jhipster-svelte](https://github.com/jhipster/generator-jhipster-svelte)
- GitHub ⭐️：63
- 负责人：[Vishal Mahajan](https://github.com/vishal423)


## JHipster Native

JHipster Native 蓝图集成 Spring Native，使用 GraalVM 创建原生二进制文件成为可能。

- 代码和文档：[jhipster/generator-jhipster-native](https://github.com/jhipster/generator-jhipster-native)
- GitHub ⭐️：41
- 负责人：[Marcelo Shima](https://github.com/mshima) 和 [Matt Raible](https://github.com/mraible)


## jOOQ

jOOQ 蓝图集成 jOOQ 作为持久化层。

- 代码和文档：[jhipster/generator-jhipster-jooq](https://github.com/jhipster/generator-jhipster-jooq)
- GitHub ⭐️：9
- 负责人：[Marcelo Shima](https://github.com/mshima)
