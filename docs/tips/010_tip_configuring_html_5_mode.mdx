# 配置 HTML 5 模式

__由 [@brevleq](https://github.com/brevleq) 提交并由 [@wmarques](https://github.com/wmarques) 更新__

#### 自从这个 [pull request #9098](https://github.com/jhipster/generator-jhipster/pull/9098) 以来，HTML 5 模式已经被添加到生成器中，所以您不再需要进行任何特定的配置！

您可能已经注意到，AngularJS 在其 URL 中使用 "#"。AngularJS 的 HTML5 模式可以从 URL 中移除这些 "#"。

## 激活 HTML 5 模式

在 `webapp/app/blocks/config/` 目录中创建 `html5.mode.config.js` 文件：

```
    (function() {
      'use strict';

      angular
        .module('<YourAppName>')
        .config(html5ModeConfig);

      html5ModeConfig.$inject = ['$locationProvider'];

      function html5ModeConfig($locationProvider) {
        $locationProvider.html5Mode({ enabled: true, requireBase: true });
      }
    })();
```

然后打开 `index.html` 并在 `head` 标签中添加这一行：

```
    <base href="/">
```

## 重定向过滤器

现在，为了使相对路径链接正常工作（例如发送到用户电子邮件的激活链接），我们将创建一个控制器将 URI 转发到 index.html：

```
    @Controller
    public class AngularJsForwardController {
        @RequestMapping(value = "/**/{[path:[^\\.]*}")
        public String redirect() {
            return "forward:/";
        }
    }
```

请注意，这可能会与 [Spring actuators URLs](https://docs.spring.io/spring-boot/docs/current/reference/html/production-ready-endpoints.html) 产生冲突。

这就是为什么您必须编辑 `metric.js` 和 `health.js` 的 URL。首先，打开 `webapp\app\admin\health\health.js` 并更改：

    url: '/health' -> url: '/apphealth'

然后对 `webapp\app\admin\metrics\metrics.js` 执行相同的操作：

    url: '/metrics' -> url: '/appmetrics'

如果您使用 gulp，则必须编辑文件 `gulp\serve.js` 并将 `proxyRoutes` 变量替换为：

    var proxyRoutes = [
        '/'
    ];

最后，为了使导航栏中的主页链接正常工作，打开 `webapp\app\layouts\navbar\navbar.html` 并更改：

```
    <a class="navbar-brand" href="#/"> -> <a class="navbar-brand" href="/">
```
