__Tip submitted by [@pascalgrimaud](https://github.com/pascalgrimaud)__

:::warning

这个提示依赖于另一个不被 JHipster 直接支持的项目。

:::

项目 [djfarrelly/maildev](https://github.com/djfarrelly/MailDev) 是一种简单的方式，可以在开发期间使用易于使用的 Web 界面测试项目生成的电子邮件。

使用 Docker 在本地启动 SMTP 服务器：

```shell
docker container run -d -p 1080:80 -p 25:25 djfarrelly/maildev
```
