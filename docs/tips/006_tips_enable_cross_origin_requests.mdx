## /!\ 此提示自 JHipster v3.0 起已弃用

__提示由 [@tomcgn](https://github.com/tomcgn) 提交__

您可能希望使用现成的 API 将您的应用程序集成到现有网站中。
一种方法可能是使用 [Knockout](https://github.com/knockout/knockout) 轻松绑定您的实体并在您的博客等地方渲染实体，这些内容从您的 JHipster 应用程序提供。

为了从简单的 HTML/AJAX 客户端使用 API，需要在标准 JHipster 代码中更改两个方面：

1. 配置 `SecurityConfiguration`
2. 告诉访问使用 API 的第三方网站的用户的浏览器，您的应用程序允许该请求的来源。


## 修改 SecurityConfiguration

在方法 `SecurityConfiguration.configure(HttpSecurity http)` 中，根据需要在 `.and().authorizeRequests()` 部分添加新指令，例如：

    .antMatchers("/api/_search/meetings/**").permitAll()
    .antMatchers("/api/_search/meetings").permitAll()`

当然，您可以使用 `.hasAuthority()` 和 `.authenticated()` 使您的瘦客户端更具动态性。


## 调整 HTTP 响应标头

您需要将以下指令添加到 `CsrfCookieGeneratorFilter`：

在方法 `doFilterInternal(HttpServletRequest request, HttpServletResponse response, FilterChain filterChain) throws ServletException, IOException` 中

    response.addHeader("Access-Control-Allow-Origin", "*");
    response.setHeader("Access-Control-Allow-Methods", "POST, GET, OPTIONS, DELETE");
    response.setHeader("Access-Control-Max-Age", "86400"); // 24 Hours
    response.setHeader("Access-Control-Allow-Headers", "Origin, X-Requested-With, Content-Type, Accept, x-auth-token");
