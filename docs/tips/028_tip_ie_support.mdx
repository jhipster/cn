**Tip submitted by [@wmarques](https://github.com/wmarques)** & [@anthony-o](https://github.com/anthony-o)

JHipster 仅支持常青浏览器。
但是，你仍然可以轻松支持一些较旧的浏览器，如 Internet Explorer。

为此，你需要：

1. 在你的 `tsconfig` 中将目标设置为 `es5`
2. 然后你有两个选项：
   - 从 'core-js' 添加正确的 polyfills，如果你不知道应该使用哪一个，请查看 Angular CLI 项目及其 polyfills。
   - 或使用 babel + [Babel preset-env](https://babeljs.io/docs/en/babel-preset-env#usebuiltins) 根据 browserslist 文件自动导入正确的 core-js polyfills。


## 使用 Babel 的完整提示

首先，添加这些 `package.json` 依赖项：`@babel/core`、`@babel/preset-env` 和 `babel-loader`。使用 `npm` 的示例：

```shell
npm install @babel/core @babel/preset-env babel-loader --save-dev
```

（在 JHipster v6.3.1 生成的应用程序上测试了以下版本以实现可运行的 IE11 版本：

```json
"@babel/core": "7.6.4",
"@babel/preset-env": "7.6.3",
"babel-loader": "8.0.6",
```
)

现在在 `src/main/webapp/app/polyfills.ts` 的顶部添加以下行：

```ts
import 'core-js/stable';
import 'regenerator-runtime/runtime';
```

在 `webpack/webpack.common.js` 中，在

```js
{
  test: /manifest.webapp$/,
  loader: 'file-loader',
  options: {
    name: 'manifest.webapp'
  }
},
```

之后添加以下行：

```js
{
  test: /\.js/,
  use: {
    loader: 'babel-loader',
    options: {
      "presets": [
        [
          "@babel/preset-env",
          {
            "targets": {
              "firefox": "60",
              "ie": "11"
            },
            "useBuiltIns": "entry",
            "corejs": 3
          }
        ]
      ]
    }
  },
  exclude: /@babel(?:\/|\\{1,2})runtime|core-js/,
},
```

最后，在 `tsconfig.json` 和 `tsconfig-aot.json` 中将 `target` 更改为 `es5`。

更多详细信息，请参见此 [GitHub issue](https://github.com/jhipster/generator-jhipster/issues/10184#issuecomment-541650501) 和 [这个 SO 回答](https://stackoverflow.com/a/58377002/535203)。
