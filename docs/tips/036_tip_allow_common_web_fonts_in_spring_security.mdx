在开发 JHipster Web 应用程序时，你可能会遇到由于安全配置而导致 Web 字体无法正常加载的问题。要允许常见的 Web 字体无缝加载，请按照以下步骤操作：

在你的 `SecurityConfiguration.java` 文件中，更新 `filterChain` 方法以允许对 Web 字体的请求：

```java
@Bean
public SecurityFilterChain filterChain(HttpSecurity http) throws Exception {
    // ...
    http
        // other configurations
        .authorizeHttpRequests(authz ->
            authz
                .requestMatchers("/", "/index.html", "/*.js", "/*.map", "/*.css").permitAll()
                .requestMatchers("/*.ico", "/*.png", "/*.svg", "/*.webapp").permitAll()
                .requestMatchers("/*.ico", "/*.png", "/*.svg", "/*.webapp", "/*.woff", "/*.woff2", "/*.ttf", "/*.otf").permitAll() // add common web font extensions here 
                .requestMatchers("/app/**").permitAll()
                // ... other configurations
}
```

通过这些调整，你的 JHipster 应用程序的安全配置将允许加载常见的 Web 字体，而不会遇到安全限制。
