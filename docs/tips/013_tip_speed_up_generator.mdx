__Tip submitted by [@pascalgrimaud](https://github.com/pascalgrimaud)__

:::warning

这些提示不适用于 npm 3+ 版本，因为它使用符号链接。

:::

使用 generator-jhipster 时，`npm install` 命令可能需要几分钟，具体取决于你的连接速度。

这个提示可以在许多情况下使用：

- 用于 JHipster 的演示，以改善你的体验
- 用于开发团队，使用 `.yo-rc.json` 更快地重新生成项目
- 用于持续集成


## 为 node_modules 创建一个新项目

创建一个包含所有 `node_modules` 库的目录，并进入该目录：

```shell
mkdir jhipster-speedup
cd jhipster-speedup
```

创建 `node_modules` 目录：

```shell
mkdir -p node_modules
```

项目结构如下：

```
jhipster-speedup
├── node_modules
```

:::warning

仅当你是 JHipster 开发者时才使用此命令。它将链接到你的 generator-jhipster fork 项目：

:::

```shell
npm link generator-jhipster
```


## 生成项目

创建一个包含你的新 JHipster 项目的目录，并进入该目录：

```shell
mkdir jhipster
cd jhipster
```

创建到 `node_modules` 目录的链接：

```shell
ln -s <your path>/jhipster-speedup/node_modules
```

生成一个新项目，并回答所有问题：

```shell
jhipster
```

第一次会花费几分钟。

接下来的几次，它会使用现有的 `node_modules` 目录，所以 npm 不会下载所有库。

:::warning

如果你使用特定的库并修改了 package.json，你应该将 `node_modules` 从 jhipster-speedup 复制到你的项目文件夹，而不是使用链接。

:::
