## mod_proxy 激活

```
a2enmod proxy
a2enmod proxy_http
a2enmod headers

service apache2 restart
```


## Virtualhost 配置

找到你的 virtualhost 443 或 80 配置所在的位置，具体取决于你的发行版。

例如在 Ubuntu 16.04 中：配置位于 **/etc/apache2/sites-availables** 目录中的 **000-default-le-ssl.conf** 文件中。

如果你不想要 SSL，这里是文件 **000-default.conf**

编辑文件并在 virtualhost 443 或 80 部分粘贴这个：

```
# Proxying kibana listenning on the port 5601 
ProxyPreserveHost On
ProxyRequests On
ProxyPass / http://localhost:5601/
ProxyPassReverse / http://localhost:5601/

# Protecting with basic authentication
<Location />
    AuthType Basic
    AuthName "Restricted Content"
    AuthUserFile /etc/apache2/.htpasswd
    Require valid-user
</Location>
```

重新加载 apache 配置：

```
service apache2 reload
```

## 生成用户名/密码

```
htpasswd /etc/apache2/.htpasswd your_user
```


## 激活 SSL

按照教程（你可以选择发行版）：[Let's encrypt - Certbot](https://certbot.eff.org/)

Certbot 将自动为你处理 Apache 中的 SSL 配置

:::warning

**不要忘记在你的防火墙中关闭端口 5601！** 因为如果你不这样做，kibana 仍然可以在没有基本认证的情况下在端口 5601 上访问

:::

现在你可以在 https://mydomain.com 或 http://mydomain.com 安全地访问 kibana 了
