**Tip submitted by [@SudharakaP](https://github.com/SudharakaP)**

在长时间运行 Docker（中间有睡眠周期）时，应该考虑的一件事是，Docker 容器和操作系统时钟之间可能会发生时间漂移。

这会导致难以发现的错误，例如 [https://github.com/jhipster/generator-jhipster/issues/11659](https://github.com/jhipster/generator-jhipster/issues/11659)。

Docker 时间漂移在 [Mac](https://github.com/docker/for-mac/issues/2076) 和 [Windows](https://github.com/docker/for-win/issues/4526) 上都有报告，
最简单的解决方案是在长时间睡眠周期后重新启动 Docker 容器。
