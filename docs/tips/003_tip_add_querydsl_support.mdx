在某些情况下，Spring Data [查询可能性](http://docs.spring.io/spring-data/mongodb/docs/current/reference/html/#mongodb.repositories.queries)不足以满足您的查询需求。您可以使用 `@Query` 注解并[编写自己的查询](http://docs.spring.io/spring-data/mongodb/docs/current/reference/html/#mongodb.repositories.queries.json-based)。我们中的一些人喜欢编写类型安全的查询，就像 [Querydsl](http://www.Querydsl.com/) 提供的那样。


## 生成的 Predicate 类

Querydsl 的重要部分是为查询生成的域类，即所谓的 Predicate。在 spring-data-mongodb 的情况下，这些是由 Java 注解后处理工具生成的。


## Gradle 插件

也有支持 spring-data-mongodb 配置的 Querydsl Gradle 插件。


## Maven 插件

也有 Maven 插件。Maven 配置在文档的 [Maven 集成](http://www.querydsl.com/static/querydsl/latest/reference/html/ch02.html#d0e132)章节中有完整描述。您还需要执行以下步骤。

:::note

不要包含 `org.slf4j` 依赖，因为它已包含在 Spring Boot 中。

:::


## 更改

### build.gradle

在 `build.gradle` 中，添加对 `Querydsl 插件` 的依赖

```groovy
buildscript {
    repositories {
        jcenter()
    }
    dependencies {
        classpath "gradle.plugin.com.ewerk.gradle.plugins:querydsl-plugin:1.0.9"
    }
}

apply from: 'gradle/querydsl.gradle'
```
定义要在 `gradle.properties` 中使用的 `Querydsl 版本`

```properties
querydsl_version=4.1.4
```

然后创建文件 `gradle/querydsl.gradle`，内容如下

```groovy
apply plugin: "com.ewerk.gradle.plugins.querydsl"

sourceSets {
    main {
        java {
            srcDir "$buildDir/generated/source/apt/main"
        }
    }
}

querydsl {
    // 我们使用 mongodb
    springDataMongo = true
    querydslSourcesDir = "$buildDir/generated/source/apt/main"
}

dependencies {
    compile "com.querydsl:querydsl-mongodb:${querydsl_version}"
    compileOnly "com.querydsl:querydsl-apt:${querydsl_version}"
}
```

:::note

我们使用 MongoDB，但 Querydsl 插件还支持[更多选项](https://github.com/ewerk/gradle-plugins/tree/master/Querydsl-plugin)。

:::

如果您运行 `gradle build`，您将看到类似这样的输出
`Note: Generating net.jogat.names.domain.QName for [net.jogat.names.domain.Name]`

对于每个用 @Document 注解的域类，Querydsl 插件都会生成一个 Predicate 类。


## 更改 Repository 类

如果您有一个域类，例如 `Name`，那么您也有一个 `NameRepository` 类。您必须更改每个 Repository 类以扩展 `QueryDslPredicateExecutor`。

```java
public interface NameRepository extends MongoRepository<Name, String>, QueryDslPredicateExecutor<Name> {}
```

这将用支持 Querydsl 的额外方法扩展您的 repository 类（[参见](http://docs.spring.io/spring-data/mongodb/docs/current/reference/html/#mongodb.repositories.queries.type-safe)）


## Web 支持

要扩展 REST 控制器以支持参数化请求，您必须将用 `org.springframework.data.querydsl.binding.QuerydslPredicate` 注解的 `com.mysema.query.types.Predicate` 添加到方法参数中：

```java
@RestController
@RequestMapping("/api")
class NameResource {

    private final NameRepository nameRepository;
    
    public NameResource(NameRepository nameRepository) {
        this.nameRepository = nameRepository;
    }

    @RequestMapping(value = "/names",
        method = RequestMethod.GET,
        produces = MediaType.APPLICATION_JSON_VALUE)
    @Timed
    public ResponseEntity<List<Name>> getAllNames(@QuerydslPredicate(root = Name.class) Predicate predicate,
                                                    Pageable pageable) {
        log.debug("REST request to get a page of Name");
        Page<Name> page = nameRepository.findAll(predicate, pageable);
        HttpHeaders headers = PaginationUtil.generatePaginationHttpHeaders(page, "/api/names");
        return new ResponseEntity<>(page.getContent(), headers, HttpStatus.OK);
    }
    ...
}
```

同样在 `NameResourceIntTest` 中，您必须支持 `QuerydslPredicateArgumentResolver`：

```java
public class NameResourceIntTest {
    ...
    @Autowired
    private NameRepository nameRepository;
    @Autowired
    private QuerydslPredicateArgumentResolver querydslPredicateArgumentResolver;

    @PostConstruct
    public void setup() {
        MockitoAnnotations.initMocks(this);
        NameResource nameResource = new nameResource(nameRepository);
        this.restNameMockMvc = MockMvcBuilders.standaloneSetup(nameResource)
            .setCustomArgumentResolvers(pageableArgumentResolver, querydslPredicateArgumentResolver)
            .setMessageConverters(jacksonMessageConverter).build();
    }
    ...
}
```

更多详细信息可以在[文档](http://docs.spring.io/spring-data/mongodb/docs/current/reference/html/#core.web.type-safe)中找到。


## 编写类型安全的查询

Gradle 或 maven 插件已生成 QName 类，可用于为 Name.class 编写查询。以下是 Java 示例：

```java
QName name = QName.name;

// 计算所有 "categorie" 列表包含字符串 "TOP_EVER" 的名称数量
nameRepository.count(name.categories.contains("TOP_EVER"));
```
