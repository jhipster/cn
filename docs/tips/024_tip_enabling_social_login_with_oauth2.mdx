使用 OAuth2 认证类型时，你的应用程序连接到 OpenID Connect 服务器，如 Okta 或 Keycloak。可以通过在管理控制台中添加外部身份提供商来启用社交登录。


## 使用 Okta 添加身份提供商

Okta 支持 Facebook、Microsoft、Google、LinkedIn 和自定义 SAML 提供商。

登录到 Okta 控制台，通过菜单导航到"Users"->"Social & Identity Providers"。选择"Add Identity Provider"并添加你选择的提供商。确保完全遵循 [Okta 社交登录文档](https://developer.okta.com/authentication-guide/social-login/)，该文档将指导你获取每个提供商的客户端 ID 和密钥。


## 使用 Keycloak 添加身份提供商

Keycloak 支持 GitHub、Twitter、Facebook、Openshift、Google、Gitlab、LinkedIn、Microsoft、BitBucket、StackOverflow 和自定义 SAML 提供商。

登录到 Keycloak 管理控制台，从左侧菜单中选择"Identity Providers"。按照 [Keycloak 社交登录文档](https://www.keycloak.org/docs/latest/server_admin/index.html#social-identity-providers)中的说明配置提供商并获取客户端 ID 和密钥。
