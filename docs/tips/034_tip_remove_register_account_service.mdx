__Tip submitted by [@apuntandoanulo](https://github.com/apuntandoanulo)__

_目标：_ 如果你想消除用户创建账户的可能性，只让之前注册的用户来做这件事，请移除下面指示的以下片段和代码行：


## 1. 在后端侧

* ___1.1___  `src\main\java\ ... \service\UserService.java`
  - 移除整个方法 `public User registerUser(...)`
* ___1.2___ `src\main\java\ ... \rest\AccountResource.java`
  - 移除整个方法 `@PostMapping("/register")   public void registerAccount(...)`


## 2. 在前端侧

* ___2.1___ `src\main\webapp\app\account`
  - 移除整个文件夹 `register`，其中包含：`register.component.html`、`register.component.ts`、`register.route.ts`、`register.service.ts`

* ___2.2___ 进入 `src\main\webapp\app\account\account.module.ts` 并移除以下行：
  - `import { RegisterComponent } from './register/register.component'; `
  - _declarations_ 数组 -> `RegisterComponent`

* ___2.3___ 进入 `src\main\webapp\app\account\account.route.ts` 并移除以下行：
  - `import { registerRoute } from './register/register.route'; `
  - _ACCOUNT_ROUTES_ 数组 -> `registerRoute `

* ___2.4___ 进入 `src\main\webapp\app\home\home.component.html` 并移除以下块：

```html
<div class="alert alert-warning" *ngSwitchCase="false">
  <span jhiTranslate="global.messages.info.register.noaccount">You don't have an account yet?</span>&nbsp;
  <a class="alert-link" routerLink="account/register" jhiTranslate="global.messages.info.register.link">Register a new account</a>
</div>
```

* ___2.5___ 进入 `src\main\webapp\app\layouts\navbar\navbar.component.html` 并移除以下块：

```html
<li *ngSwitchCase="false">
  <a class="dropdown-item" routerLink="account/register" routerLinkActive="active" (click)="collapseNavbar()">
      <fa-icon icon="user-plus" [fixedWidth]="true"></fa-icon>
      <span jhiTranslate="global.menu.account.register">Register</span>
  </a>
</li>
```

* ___2.6___ 进入 `src\main\webapp\app\shared\login\login.component.html` 并移除以下块：

```html
<div class="alert alert-warning">
  <span jhiTranslate="global.messages.info.register.noaccount">You don't have an account yet?</span>
  <a class="alert-link" (click)="register()" jhiTranslate="global.messages.info.register.link">Register a new account</a>
</div>
```

* ___2.7___ 进入 `src\main\webapp\app\shared\login\login.component.ts` 并移除以下块：

```ts
register(): void {
  this.activeModal.dismiss('to state register');
  this.router.navigate(['/account/register']);
}
```

* ___2.8___ 移除消息文件：`src\main\webapp\i18n\ ... \register.json`

* ___2.9___ `src\test\javascript\spec\app\account`
  - 移除整个文件夹 `register`，其中包含：`register.component.spec.ts`
