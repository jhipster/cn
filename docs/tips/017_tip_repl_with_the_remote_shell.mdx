__Tip submitted by [@cbornet](https://github.com/cbornet)__

**由于 Spring Boot 远程 shell 将在 Spring Boot 2.0 中被移除，此提示已弃用**

从 v3.8 版本开始，JHipster 有一个 `shell` Maven/Gradle 配置文件，它将包含 [Spring Boot 远程 shell](http://docs.spring.io/spring-boot/docs/current/reference/html/production-ready-remote-shell.html)。
如果你的项目是用 JHipster < 3.8 生成的，你需要手动添加 `spring-boot-starter-remote-shell` 依赖。

这带来了一些有用的命令，可以帮助调试运行中的应用程序，你也可以编写自己的命令。

另一个在 Spring Boot 文档中没有记录的不错功能是，你可以在运行中的应用程序上以 [REPL](https://en.wikipedia.org/wiki/Read%E2%80%93eval%E2%80%93print_loop) 的方式执行 Groovy 脚本代码。
为此：

  * 启动你的应用

  * 在终端中打开一个 ssh 会话（这里以用户 admin，密码：admin 为例）：

```shell
ssh -p2000 admin@localhost
```

* 连接后，切换到 Groovy REPL 模式：

```shell
> repl groovy
```

* 获取 BeanFactory：

```shell
> bf = context.attributes['spring.beanfactory']
```

* 现在你可以使用 BeanFactory 获取 Spring bean 并调用它们的方法：

```shell
> bf.getBean('userRepository').findAll().login
[system, anonymoususer, admin, user]
> bf.getBean('userService').getUserWithAuthoritiesByLogin('user').get().authorities.name
[ROLE_USER]
```
