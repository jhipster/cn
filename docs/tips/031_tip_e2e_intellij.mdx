**Tip submitted by [@SudharakaP](https://github.com/SudharakaP) and [@yelhouti](https://github.com/yelhouti)**

此提示适用于 JHipster v6.8.0 或更高版本。默认情况下，JHipster 项目将在 Protractor 配置文件（`src/test/javascript/protractor.conf.js`）中包含以下 `beforeLanuch` 函数。 

```js
beforeLaunch: function() {
  require('ts-node').register({
    project: 'tsconfig.e2e.json'
  });
}
``` 

如果在项目的根文件夹中运行 `npm run e2e` 来执行 Protractor 测试，这将运行良好。

但是，IntelliJ Ultimate 也支持[在 IDE 中运行 Protractor 测试](https://www.jetbrains.com/help/idea/protractor.html#ws_protractor_running)。
如果你想使用此方法，你需要按如下所示更改 `beforeLanuch` 函数； 

```js
beforeLaunch: function() {
  require('ts-node').register({
    project: '../../../tsconfig.e2e.json'
  });
}
``` 

这样 IntelliJ 就知道在哪里找到 `tsconfig.e2e.json` 文件了。

请注意，按上述方式修改 `protractor.conf.js` 文件后，`npm run e2e` 将不再工作，因此如果你打算再次使用 npm 运行 e2e 测试，你需要回滚。
