在使用 JHipster Quarkus 之前，您必须准备您的环境（Java、Node）并安装 JHipster。

请参考文档 https://www.jhipster.tech/installation/ 中的“使用 NPM 本地安装（推荐给普通用户）”部分。

现在您可以安装 JHipster Quarkus 蓝图：

`npm install -g generator-jhipster-quarkus`

您可以通过检查 `jhipster-quarkus` 命令的存在来验证安装：`which jhipster-quarkus`（适用于 Mac/Linux）。

完成了。现在您可以开始使用 JHipster 创建 Quarkus 应用程序。
