## Java 代码支持

Visual Studio Code 有一个由 Red Hat 开发的 Java 扩展。它有很好的 Java 支持，使用 Maven 或 Gradle。

您可以使用 Visual Studio Code 市场安装它：

![Screenshot](/images/configuring_ide_visual_studio_code_3.png)


## 常见任务：编译、运行和打包代码

Visual Studio Code Java 扩展不能用于运行命令：它不能编译、运行代码或打包应用程序。

对于所有这些任务，有 2 种解决方案：

- 使用终端，例如 Visual Studio Code 提供的内部终端，手动运行这些命令
- 使用 [JHipster App](/jhipster-app)，它为所有这些命令提供图形界面。**注意：**JHipster App 已弃用。


## 使用 Spring Boot devtools 实现应用程序“热重启”

[Spring Boot devtools](https://docs.spring.io/spring-boot/docs/current/reference/html/using-boot-devtools.html) 由 JHipster 配置，并将在编译项目中的类时“热重启”您的应用程序。这是一个必备功能，因为它使您的应用程序实时更新。

要在 Visual Studio Code 中使用它，您需要：

- 在终端中运行您的应用程序，通常通过输入 `./mvnw`
- 在另一个终端中，编译您的应用程序：`./mvnw compile`

在第一个终端中，您的 JHipster 应用程序应该自动重新部署，并使用您的新代码。

如果您使用 JHipster App，这只是点击 2 个按钮的问题（一个用于运行应用程序，另一个用于编译它），您的应用程序将以相同的方式自动重新部署。


## 自定义设置

为了获得最佳性能，建议排除一些文件夹，在您项目的 `.vscode` 文件夹中创建一个 `settings.json` 文件，如下所示：

```
{
    // Configure glob patterns for excluding files and folders.
    "files.exclude": {
        "**/.git": true,
        "**/.gradle": true,
        "**/.idea": true,
        "**/.mvn": true,
        "**/.svn": true,
        "**/.hg": true,
        "**/.DS_Store": true
    },
    // Configure glob patterns for excluding files and folders in searches. Inherits all glob patterns from the files.exclude setting.
    "search.exclude": {
        "**/node": true,
        "**/node_modules": true,
        "**/bower_components": true,
        "**/build": true,
        "**/target": true
    }
}
```
