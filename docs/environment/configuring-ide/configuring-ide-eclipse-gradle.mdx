要在 Eclipse 中获得完整的 Gradle 支持，您应该安装 [buildship 插件](https://gradle.org/eclipse/)。
对于配置 [JavaScript](/configuring-ide-eclipse) 方面，您可以按照 Maven 的说明进行操作。


## 1. 将您的项目作为 Gradle 项目导入

- 选择 ``File -> Import``
- 选择 ``Gradle Project``
- 选择您的项目根目录
- 点击 ``Next`` 并完成向导

![Import](/images/configuring_ide_eclipse_gradle_1.png)

![Select](/images/configuring_ide_eclipse_gradle_2.png)


## 2. 将 apt 生成的源文件夹添加到构建路径

当使用 buildship 时，gradle 的默认输出文件夹被过滤且在您的工作区中不可见。
因此，您需要从 Eclipse 的资源过滤器设置中删除它。

- 右键单击您的项目并选择 ``Properties``
- 选择 ``Resources``
- 删除条目 ``build``
- 选择 ``Java Build Path``
- 点击 ``Add Folder...``
- 勾选路径 ``build/generated/source/apt/main``

确保在通过 Eclipse 运行 JHipster 时，新的源文件夹包含正确生成的 mapper 实现。
