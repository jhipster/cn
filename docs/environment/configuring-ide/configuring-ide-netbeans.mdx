在 NetBeans 中导入您的 JHipster 应用程序非常简单。

## 1. 打开您的项目

- 选择 File -> Open Project
- 浏览并选择您的项目文件夹

![Open](/images/configuring_ide_netbeans_1.png)

**就是这样**：要运行您的项目，右键单击 Application 类（在包层次结构的根部）并选择 "Run File"。

![Open](/images/configuring_ide_netbeans_2.png)
