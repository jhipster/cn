Shell 插件为使用 JHipster 提供了额外的快捷方式，使其使用更快、更简单。如果您见过人们拥有美丽的 shell，具有好的自动完成和超快的快捷方式，魔法就来自这里！

目前有两个 shell 插件：

- [Oh-My-Zsh JHipster 插件](/oh-my-zsh) 用于 [Oh-My-Zsh](https://ohmyz.sh/)
- [Fisher JHipster 插件](/fisher) 用于 [Fisher](https://github.com/jorgebucaran/fisher)
