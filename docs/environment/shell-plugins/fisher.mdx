如果您使用 Linux 或 Mac OS X，[fisher](https://github.com/jorgebucaran/fisher) 是管理您的 [fish shell](http://fishshell.com/) 配置的绝佳工具。

JHipster 开发团队的一些成员使用 fish shell 和 Fisher，如果您看到人们在终端中使用快捷方式，魔法就来自这里！


## Fisher JHipster 插件

JHipster Fisher 插件在 GitHub 上可用，地址为 [https://github.com/jhipster/jhipster-fisher-plugin](https://github.com/jhipster/jhipster-fisher-plugin)。

目前它只添加了快捷方式（完整列表请参见[这里](https://github.com/jhipster/jhipster-fisher-plugin/blob/main/conf.d/jhipster.aliases.fish)），但我们欢迎贡献以获得更好的自动完成！

1. 通过 `fisher` 命令安装它：

    ```shell
    fisher install jhipster/jhipster-fisher-plugin
    ```

有关 [Fisher](https://github.com/jorgebucaran/fisher) 的更多详细信息，请查看它们的[使用](https://github.com/jorgebucaran/fisher#usage)部分。
