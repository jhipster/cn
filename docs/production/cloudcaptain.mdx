本指南展示了如何使用 [CloudCaptain](https://cloudcaptain.sh/) 将您的 JHipster 应用程序部署到 AWS。

[![CloudCaptain](/images/logo/logo-cloudcaptain.png)](https://cloudcaptain.sh/)

CloudCaptain **对 JHipster 提供一流的支持**，通过为您的应用程序创建最小的不可变机器映像，然后可以在 VirtualBox 或 AWS 上部署。


## 先决条件

要能够部署，您必须首先[创建 CloudCaptain 账户](https://console.cloudcaptain.sh)并安装 [CloudCaptain 客户端](https://cloudcaptain.sh/getstarted/download)。

您还需要在 [CloudCaptain 控制台](https://console.cloudcaptain.sh)中连接您的 AWS 账户。


## 准备部署

当您的应用程序准备就绪时，您可以通过输入以下命令为部署做准备：

```shell
./mvnw package -Pprod -DskipTests
```

或者在使用 gradle 时：

```shell
./gradlew -Pprod bootJar -x test
```


## 部署到 AWS

要将您的应用程序部署到 AWS，请输入：

```shell
boxfuse run -env=prod
```

CloudCaptain 然后会分析您的应用程序，为其融合一个最小的机器映像，并自动配置、设置和保护所有必要的
AWS 基础设施（实例、安全组、弹性 IP、ELB、MySQL 或 PostgreSQL RDS 数据库...）

如果您想覆盖这些自动发现的设置，您可以这样做，但在大多数情况下您不需要。


## 部署更新

要将更新部署到现有应用程序，请遵循上述的准备和部署步骤。所有更新
都作为零停机时间的蓝绿部署执行。
