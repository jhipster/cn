## Jenkins 配置

要在 Jenkins 中设置 JHipster 项目，请使用以下配置：

### 对于 Maven：

```
* 项目名称： `yourApplicationName`
* 源代码管理
    * Git 仓库： `git@github.com:xxxx/yourApplicationName.git`
    * 要构建的分支： `*/main`
    * 附加行为： `清空仓库并强制克隆`
* 构建触发器
    * 轮询 SCM / 计划： `H/5 * * * *`
* 构建<% if (buildTool == 'maven') { %>
    * 调用 Maven / 任务： `-Pprod clean package`
    * 执行 Shell / 命令：
        mvn spring-boot:run &
        bootPid=$!
        sleep 30s
        gulp itest
        kill $bootPid
* 构建后操作
    * 发布 JUnit 测试结果报告 / 测试报告 XML： `build/test-results/*.xml`
```

### 对于 Gradle：

```
* 项目名称： `yourApplicationName`
* 源代码管理
    * Git 仓库： `git@github.com:xxxx/yourApplicationName.git`
    * 要构建的分支： `*/main`
    * 附加行为： `清空仓库并强制克隆`
* 构建触发器
    * 轮询 SCM / 计划： `H/5 * * * *`
* 构建
    * 调用 Gradle 脚本 / 使用 Gradle Wrapper / 任务： `-Pprod clean test bootWar`
    * 执行 Shell / 命令：
        ./gradlew bootRun &
        bootPid=$!
        sleep 30s
        gulp itest
        kill $bootPid
* 构建后操作
    * 发布 JUnit 测试结果报告 / 测试报告 XML： `build/test-results/*.xml`
```
