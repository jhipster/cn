## 安装 Jenkins

从 [https://jenkins.io/](https://jenkins.io/) 下载 Jenkins Windows 安装程序

安装程序将 Jenkins 配置为使用 SYSTEM 用户作为服务运行，这可能存在安全风险，更安全的做法是将服务的用户更改为非特权用户：

[http://antagonisticpleiotropy.blogspot.fr/2012/08/running-jenkins-in-windows-with-regular.html](http://antagonisticpleiotropy.blogspot.fr/2012/08/running-jenkins-in-windows-with-regular.html)


## 配置 Jenkins

### 安装 JDK 8

通过 Jenkins 管理界面，添加 JDK 8 自动安装程序。

### 安装 Maven

通过 Jenkins 管理界面，从 Apache 网站添加 Maven 自动安装程序。

### 安装 PhantomJS

从 [http://phantomjs.org/download.html](http://phantomjs.org/download.html) 安装二进制文件

检查可执行文件是否包含在 PATH 中：

```shell
phantomjs --version
2.1.1
```


## 安装 NodeJS

Jenkins NodeJS 插件在 Windows 上不工作，所以我们需要手动安装。

从 [http://nodejs.org/](http://nodejs.org/) 下载最新的 LTS（长期支持）64位版本

不要将 NodeJS 安装到默认目录 `C:\Program Files\nodejs`，因为这需要管理员权限，建议使用更简单的路径，如 `c:\nodejs`。

编辑 `C:
odejs
ode_modules
pm
pmrc` 文件，将

```
prefix=${APPDATA}\npm
```

by

```
prefix=C:\nodejs\node_modules\npm
```

将 'C:\nodejs\node_modules\npm' 文件夹添加到 PATH 环境变量中，移除安装程序添加的路径：'C:\Users\<user>\AppData\Roaming\npm'

npm 可能需要 Git，从 [https://git-for-windows.github.io/](https://git-for-windows.github.io/) 安装

添加 Bower 和 Gulp：

```shell
npm install -g bower gulp
bower --version
gulp --version
```

在同一台机器上拥有多个版本的 NodeJS 可能很有用，但 Windows 上的 `nvm` 等价工具更专注于开发环境而非持续集成。因此，如果作业需要另一个版本的 NodeJS，请更改其 PATH 变量。
