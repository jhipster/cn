## 介绍

在生成新项目期间，您将被问及是否要启用国际化支持。

如果启用它，您需要选择应用程序的本地语言。之后，您可以选择要安装的其他语言。如果您一开始不想支持任何其他语言，您可以在需要时通过运行语言子生成器来添加语言。

如果您确定永远不会将此应用程序翻译成另一种语言，您应该不启用国际化。

## 如何在项目生成后添加语言？

要做到这一点，您可以使用以下命令运行语言子生成器：

`jhipster languages`

![](/images/install_new_languages.png)

请注意，如果您希望将实体翻译为您刚刚添加的语言，您需要重新生成您的实体。


## 如何添加不支持的新语言？

所有语言都保存在文件夹 `src/main/webapp/i18n`（客户端）和 `src/main/resources/i18n`（服务器端）中

以下是安装名为 `new_lang` 的新语言的步骤：

1.  将 `src/main/webapp/i18/en` 文件夹复制到 `src/main/webapp/i18/new_lang`（这是存储所有前端翻译的地方）
2.  翻译 `src/main/webapp/i18/new_lang` 文件夹下的所有文件
3.  将语言代码 `new_lang` 添加到 `src/main/webapp/app/shared/language/find-language-from-key-pipe.ts` 中定义的 `languages` 变量

```ts
private languages: { [key: string]: { name: string; rtl?: boolean } } = {
    en: { name: 'English' },
    new_lang: { name: 'New Language' }
    // jhipster-needle-i18n-language-key-pipe - JHipster will add/remove languages in this object
};
```

4.  在 `src/main/resources/i18n` 文件夹中，将 `messages_en.properties` 文件复制到 `messages_new_lang.properties`（这是存储服务器端翻译的地方）
5.  翻译 `messages_new_lang.properties` 文件中的所有键
6.  在 `webpack/webpack.common.js` 中添加新语言打包

```js
new MergeJsonWebpackPlugin({
    output: {
        groupBy: [
            { pattern: "./src/main/webapp/i18n/en/*.json", fileName: "./i18n/en.json" },
            { pattern: "./src/main/webapp/i18n/new_lang/*.json", fileName: "./i18n/new_lang.json" }
            // jhipster-needle-i18n-language-webpack - JHipster will add/remove languages in this array
        ]
    }
})
```

新语言 `new_lang` 现在在语言菜单中可用，并且在前端 Angular 应用程序和后端 Spring 应用程序中都可用。

### 向 generator-jhipster 贡献语言

如果您希望向生成器贡献新语言，请按照以下步骤；

- 在 [`generators/generator-constants.js`](https://github.com/jhipster/generator-jhipster/blob/main/generators/generator-constants.js) 中将该语言添加到 `LANGUAGES` 常量

```js
{ name: 'New Language', dispName: 'New Language', value: 'nl' }
```

- 将文件 [`generators/languages/templates/src/main/resources/i18n/messages_en.properties.ejs`](https://github.com/jhipster/generator-jhipster/blob/main/generators/languages/templates/src/main/resources/i18n/messages_en.properties.ejs) 复制到 `generators/languages/templates/src/main/resources/i18n/messages_nl.properties.ejs` 并将所有值翻译为新语言。

- 将文件夹 [`generators/languages/templates/src/main/webapp/i18n/en`](https://github.com/jhipster/generator-jhipster/tree/main/generators/languages/templates/src/main/webapp/i18n/en) 复制到 `generators/languages/templates/src/main/webapp/i18n/nl` 并翻译其中的所有文件。

- 将文件 [`generators/entity-i18n/templates/i18n/entity_en.json.ejs`](https://github.com/jhipster/generator-jhipster/blob/main/generators/entity-i18n/templates/i18n/entity_en.json.ejs) 复制到 `generators/entity-i18n/templates/i18n/entity_nl.json.ejs` 并翻译其中的所有值。

- 将文件 [`generators/languages/templates/src/test/resources/i18n/messages_en.properties.ejs`](https://github.com/jhipster/generator-jhipster/blob/main/generators/server/templates/src/test/resources/i18n/messages_en.properties.ejs) 复制到 `generators/languages/templates/src/test/resources/i18n/messages_nl.properties.ejs` 并翻译其中的所有值。

- 在 [`test/templates/all-languages/.yo-rc.json`](https://github.com/jhipster/generator-jhipster/blob/main/test/templates/all-languages/.yo-rc.json) 中将语言值 `nl` 添加到 `language` 数组。

提交包含所有这些更改的 PR。


## 如何删除现有语言？

以下是删除名为 `old_lang` 语言的步骤：

1.  从 `src/main/webapp/i18/old_lang` 删除整个语言文件夹
2.  在 `src/main/webapp/app/core/language/language.constants.ts` 中删除 `LANGUAGES` 的常量条目
3.  在 `src/main/webapp/app/shared/language/find-language-from-key.pipe.ts` 中删除 `languages` 的常量条目
4.  在 `webpack/webpack.prod.js` 中删除 `localesToKeep` 的常量条目
5.  在 `webpack/webpack.common.js` 中删除 `MergeJsonWebpackPlugin` 的模式
6.  删除 `src/main/resources/i18n/messages_old_lang.properties` 文件
7.  删除 `src/test/resources/i18n/messages_old_lang.properties` 文件
