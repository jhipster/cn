JHipster 带有两个 [Spring 配置文件](http://docs.spring.io/spring-boot/docs/current/reference/html/boot-features-profiles.html)：

* `dev` 用于开发：它专注于开发的易用性和生产力
* `prod` 用于生产：它专注于性能和可扩展性

这些配置文件有两种不同的配置：

* Maven/Gradle 配置文件在构建时使用。例如 `./mvnw -Pprod package` 或 `./gradlew -Pprod bootJar` 将打包一个生产应用程序。
* Spring 配置文件在运行时工作。一些 Spring bean 的行为会有所不同，具体取决于配置文件。

Spring 配置文件由 Maven/Gradle 设置，因此我们在两种方法之间具有一致性：您将同时在 Maven/Gradle 和 Spring 上拥有 `prod` 配置文件。

_注意：_ Spring 配置文件用于配置 JHipster 应用程序属性，因此您应该有兴趣阅读我们的[通用应用程序属性文档](/common-application-properties)。


## 默认情况下，JHipster 将使用 `dev` 配置文件

如果您在不使用 Maven/Gradle 的情况下运行应用程序，请启动 "Application" 类（您可能可以通过右键单击直接从 IDE 中运行它）。

如果您使用 Maven 运行应用程序，请运行 `./mvnw` 使用我们的 Maven 包装器，或者运行 `mvn` 使用您自己的 Maven 安装。

如果您使用 Gradle 运行应用程序，请运行 `./gradlew` 使用我们的 Gradle 包装器，或者运行 `gradle` 使用您自己的 Gradle 安装。

当使用 Angular 2+ 和 Maven 时，如果您需要在 `dev` 配置文件中启用 webpack 编译进行干净运行，您可以传递 `webapp` 参数，如下所示：

```shell
./mvnw -Pdev,webapp
```

**注意** 如果前端发生了变化，Gradle 会在 `dev` 配置文件中自动运行 webpack 编译（仅在启动时，要实时重载请使用 `npm start`）。


## 在生产中，JHipster 必须使用 `prod` 配置文件运行

您可以直接使用 Maven 或 Gradle 在生产中运行 JHipster：

* 使用 Maven，运行 `./mvnw -Pprod`（或 `mvn -Pprod`）
* 使用 Gradle，运行 `./gradlew -Pprod`（或 `gradle -Pprod`）

如果您想将应用程序打包为可执行的 WAR 文件，您应该为 Maven 或 Gradle 提供一个配置文件。例如：

* 使用 Maven，运行 `./mvnw -Pprod package`（或 `mvn -Pprod package`）
* 使用 Gradle，运行 `./gradlew -Pprod bootJar`（或 `gradle -Pprod bootJar`）

当您从 WAR 文件运行生产应用程序时，默认情况下使用与打包时相同的配置文件。如果您想覆盖此设置，您可以在 VM 参数中显式提供一个替代方案：

```shell
java -jar jhipster-0.0.1-SNAPSHOT.jar --spring.profiles.active=...
```


## Spring 配置文件开关

JHipster 带有三个额外的配置文件用作开关：

* `api-docs` 启用 swagger
* `no-liquibase` 禁用 liquibase
* `tls` 启用 TLS 安全性并使用 HTTP/2 协议（请参阅 [TLS 和 HTTP/2 文档](/tls)）

这些可以与 `dev` 和 `prod` 配置文件一起使用。请注意，默认情况下，`api-docs` 配置文件在 `prod` 中未启用，在 `dev` 中通过在 `application.yml` 中设置 `spring.profiles.group.dev` 配置文件组属性而启用。

`api-docs`、`no-liquibase`、`tls` 仅在运行时使用：

* 在您的 IDE 中，使用 `spring.profiles.active=dev,no-liquibase` 运行您的主应用程序类（请注意，您需要显式包含 `dev` 或 `prod` 配置文件）
* 使用打包的应用程序：`./java -jar jhipster-0.0.1-SNAPSHOT.war --spring.profiles.active=prod,no-liquibase`

使用 Maven，您也可以直接使用这些配置文件：

```shell
./mvnw -Pprod,api-docs,no-liquibase
```

```shell
./mvnw -Pdev,no-liquibase
```

使用 Gradle，您也可以直接使用这些配置文件：

```shell
./gradlew -Pprod -Papi-docs -Pno-liquibase
```

```shell
./gradlew -Pno-liquibase
```
