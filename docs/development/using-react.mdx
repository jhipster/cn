## 项目结构

JHipster 客户端代码位于 `src/main/webapp` 目录下，并且密切遵循 [Piotr Witek React 风格指南](https://github.com/piotrwitek/react-redux-typescript-guide/blob/master/README.md)。

如果您对我们的应用程序结构、文件名、TypeScript 约定等有任何问题，请先阅读这个指南...

对于 React 路由，我们遵循破折号命名约定，以便 URL 清晰一致。
当您生成一个实体时，路由名称、路由 URL 和 REST API 端点 URL 都是按照这个约定生成的，并且在需要的地方，实体名称会自动复数化。

## Redux

[Redux](https://redux.js.org/) 是一个可预测的 JavaScript 状态容器。它与 React 一起使用来管理 React 组件的状态。

Redux 提供了一个对象 **store**，用于存储您应用程序的整个状态。
要访问这个 store 并因此更新您的状态组件，唯一的方法是分发
**actions**，它描述了请求更新的事实，然后 **reducers** 将
定义状态如何响应这些操作而更新。

以下是一个 reducer 的示例：

```ts
export const ACTION_TYPES = {
  FETCH_FOOS: 'foo/FETCH_FOOS',
};

const initialState = {
  loading: false,
  foos: [],
  updateSuccess: false,
  updateFailure: false
};

// Reducer
export default (state = initialState, action) => {
  switch (action.type) {
    case REQUEST(ACTION_TYPES.FETCH_FOOS):
      return {
        ...state,
        updateSuccess: false,
        updateFailure: false,
        loading: true
      };
    case FAILURE(ACTION_TYPES.FETCH_FOOS):
      return {
        ...state,
        loading: false,
        updateSuccess: false,
        updateFailure: true
      };
    case SUCCESS(ACTION_TYPES.FETCH_FOOS):
      return {
        ...state,
        loading: false,
        updateSuccess: true,
        updateFailure: false,
        foos: action.payload.data
      };
    default:
      return state;
  }
};
```

为了访问您的 store 并更新当前应用程序状态，您需要向 store 分发
操作，如前所述。操作是 JavaScript 对象，必须有一个 **type**，描述
操作将要执行的内容，通常它们还有一个 **payload**，对应于
您想要传递给 store 的数据。

以下是一个访问 store 的操作：

```ts
const apiUrl = SERVER_API_URL + '/api/foos';

// Action
export const getFoos = () => ({
  type: ACTION_TYPES.FETCH_FOOS,
  payload: axios.get(apiUrl)
});
```

上面描述的操作表明我们想要通过发送 GET 请求来检索所有 Foo 对象。操作类型将匹配
请注意，使用 **export** 关键字是为了能够连接的组件在必要时使用该操作（例如，每次组件更新时）。


## 授权

Jhipster 使用 [React router](https://github.com/ReactTraining/react-router) 来组织您应用程序的不同部分。

当涉及需要认证的路由时，使用生成的 `PrivateRoute` 组件。这个组件将阻止任何未认证的用户访问路由。

以下是 PrivateRoute 用法的示例：

```ts
const Routes = () => (
  <div className="view-routes">
    <Route exact path="/" component={Home} />
    <Route path="/login" component={Login} />
    <PrivateRoute path="/account" component={Account} />
  </div>
);
```

如您所见，未认证的用户可以访问 `/` 和 `/login`，但访问 `/account` 需要登录。

请注意，PrivateRoute 使用 `authentication.isAuthenticated` 存储值来知道用户是否已认证。


## 通知系统

JHipster 使用 [react-toastify](https://github.com/fkhadra/react-toastify) 警告作为通知系统。

默认情况下，JHipster 将在创建/更新/删除实体时显示成功通知，
在从响应中捕获到错误时显示错误通知。

[react-jhipster](https://github.com/jhipster/react-jhipster) 库为生成的应用程序提供实用程序和通用服务。它也处理 i18n。
