## 介绍

本页面用于在开发中使用 TLS 和 HTTP/2（主要用于测试目的）。对于生产配置，请阅读[生产文档中的安全部分](/production/#security)。

TLS 是在使用 `https://` URL 时使用的协议，为了在现代浏览器上使用 HTTP/2，需要该协议。

在测试应用程序时使用这些协议很有用，主要是出于性能原因。


## 在 Spring Boot 中使用 TLS 和 HTTP/2

JHipster 有特定的配置来配置 TLS 和 HTTP/2（请参见[通用应用程序属性文档](/common-application-properties)），为了让事情更简单：

- JHipster 在应用程序生成时生成一个自签名证书
- 提供了一个特定的 `tls` 配置文件（请参见[配置文件文档](/profiles)）

为了使用提供的自签名证书运行 JHipster，并启用 TLS 和 HTTP/2，您需要使用 `tls` 配置文件：

*   使用 Maven：`./mvnw -Pdev,tls`
*   使用 Gradle：`./gradlew -Ptls`

应用程序将在 `https://localhost:8080/` 上可用。

由于证书是自签名的，您的浏览器将发出警告，您需要忽略它（或导入它）以便访问应用程序。


## 在 Angular、React 或 Vue.js 中使用 TLS 和 HTTP/2

不要使用 `npm start` 来运行前端（使用 Webpack 和 BrowserSync），而是运行 `npm run start-tls`，它将连接到在 `https://localhost:8080/` 上运行的后端。

然后一切都应该与没有 TLS 和 HTTP/2 时一样工作。
