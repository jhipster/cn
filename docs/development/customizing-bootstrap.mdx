## 基本自定义
:::tip
不要忘记运行 `npm start` 来即时获得您更改的反馈！
:::

自定义 JHipster 应用程序外观的最简单方法是在 `src/main/webapp/content/css/global.css` 中重写 CSS 样式，或者如果您选择了 Sass 选项，则在 `src/main/webapp/content/scss/global.scss` 文件中重写。

使用 Sass 比纯 CSS 更简单、更简洁且更强大，因为 Bootstrap 也是用 Sass 编写的，请参考 Bootstrap 关于主题的[官方文档](https://getbootstrap.com/docs/5.3/customize/sass/)。

如果您想在自己的 `scss` 文件中使用 Bootstrap [partials](https://sass-lang.com/guide/#partials)，那么请在 `scss` 文件的开头按以下方式导入。
例如，使用 border-radius mixin：

```css
@import "node_modules/bootstrap/scss/variables";
@import "node_modules/bootstrap/scss/mixins/border-radius";
```

确保您只导入 partials 而不是主 Sass 文件，否则您将会生成重复的 CSS，这可能会导致问题。

要更改默认的 Bootstrap 设置（如颜色、边框圆角等），请在 partial 文件 `src/main/webapp/content/scss/_bootstrap-variables.scss` 中添加或更改属性的值

在 Bootstrap [_variables.scss](https://github.com/twbs/bootstrap/blob/main/scss/_variables.scss) 中定义的所有值都可以在这里被重写。
