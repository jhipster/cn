## 欢迎来到 JHipster 网站！

您可能是通过在使用 JHipster 开发的应用程序中点击错误消息而找到这个页面的。

JHipster 是一个应用程序生成器，用于开发您正在使用的应用程序。您可以通过访问我们的[主页](/) 来查找有关 JHipster 的更多信息。

请在下面查找有关发生错误的一些信息。


## 错误：无效密码

### 错误描述

这是一个 JHipster 错误，当终端用户输入无效密码时使用。

### 如何自定义这个页面？

错误页面在每个应用程序的 `ErrorConstants` 类中配置。如果您想在您的应用程序中提供您自己的错误页面，请相应地修改此类。
