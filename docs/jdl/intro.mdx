JDL 是 JHipster 特有的领域语言，您可以在其中使用用户友好的语法在单个文件（或多个文件）中描述您的所有应用程序、部署、实体和它们的关系。

您可以使用我们的在线 [JDL-Studio](https://start.jhipster.tech/jdl-studio/) 或以下可用的 
[JHipster IDE](/jhipster-ide) 插件/扩展之一：

- [IntelliJ](https://plugins.jetbrains.com/plugin/19697-jhipster-jdl)
- [Eclipse](https://marketplace.eclipse.org/content/jhipster-ide), 
- [VS Code](https://marketplace.visualstudio.com/items?itemName=jhipster-ide.jdl)

来创建 JDL 文件及其 UML 可视化。您也可以创建并导出或分享您的 JDL 模型的 URL。

这可以作为[实体子生成器](/creating-an-entity)的替代品，也是推荐的方法。
其理念是使用可视化工具[管理关系](/managing-relationships)比使用经典的 Yeoman 问答模式要容易得多。

JDL 项目可以在 [GitHub 上找到](https://github.com/jhipster/generator-jhipster/)，它是一个像 JHipster 一样的开源项目（Apache 2.0 许可证）。它也可以作为 node 库来进行 JDL 解析。

_如果您喜欢 [JHipster 领域语言](https://github.com/jhipster/generator-jhipster/)、
[JDL Studio](https://github.com/jhipster/jdl-studio/) 或
[JHipster IDE](https://github.com/jhipster/jhipster-ide/)，请不要忘记在
[GitHub](https://github.com/jhipster/) 上为它们点星 - 谢谢_！
