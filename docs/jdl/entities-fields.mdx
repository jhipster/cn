## 语法

实体声明如下：

```jdl
[<entity javadoc>]
[<entity annotation>*]
entity <entity name> [(<table name>)] {
  [<field javadoc>]
  [<field annotation>*]
  <field name> <field type> [<validation>*]
}
```

- `<entity name>` 实体的名称，
- `<field name>` 实体的某个字段的名称，
- `<field type>` 字段的 JHipster 支持的类型，
- 可选项：
  - `<entity javadoc>` 实体的文档，
  - `<entity annotation>` 实体的选项（请参阅 [OptionsEntity][] 以获取可用选项的完整列表），
  - `<table name>` 数据库表名（如果您想指定与从实体名称自动计算的名称不同的名称），
  - `<field javadoc>` 字段的文档，
  - `<field annotation>` 字段的选项（请参阅 [OptionsField][] 以获取可用选项的完整列表），
  - `<validation>` 字段的验证。


## 示例

### 基本示例

```jdl
entity A
```

这等同于：

```jdl
entity A(a) {}
```

前者是更简单的形式，没有指定"主体"（字段的大括号）和表名。

### 使用自定义表名

也可以指定自定义表名：

```jdl
 entity A(my_super_entity)
```

### 包含字段

```jdl
entity A {
  name String required
  age Integer
}
```

### 包含字段验证

```jdl
entity A {
  name String required
  age Integer min(42) max(42)
}
```

### Blob 声明

JHipster 提供了绝佳的选择，因为可以在图像类型或任何二进制类型之间进行选择。JDL 让您做同样的事情。
使用编辑器创建一个自定义类型（请参阅 DataType），根据这些约定命名：
  - `AnyBlob` 或 `Blob` 创建一个"任意"二进制类型的字段；
  - `ImageBlob` 创建一个用作图像的字段。
  - `TextBlob` 创建一个用于 CLOB（长文本）的字段。

您可以创建任意数量的 DataTypes。

### 正则表达式

这是一种特定的验证（仅可用于 String 类型），其语法是：

```jdl
entity A {
  name String pattern(/^[A-Z][a-z]+\d$/)
}
```

让我们分解一下：

- `pattern` 是声明正则表达式验证的关键字（使用正常的圆括号）
- `/.../` 模式在两个斜线内声明
- `\` 反斜线不需要转义

### 注释

在 JDL 中可以对实体和字段进行注释，并将生成文档（Javadoc 或 JSDoc，取决于后端）。

```jdl
/**
 * This is a comment
 * about a class
 * @author Someone
 */
entity A {
  /**
   * This comment will also be used!
   * @type...
   */
   name String
   age Integer // this is yet another comment
}
```

这些注释将由 JHipster 后续添加为 Javadoc 注释。JDL 拥有自己的注释类型：
  - // 一个被忽略的注释
  - /** 不被忽略的注释 */

因此，任何以 `//` 开头的内容都被认为是 JDL 的内部注释，不会被计为 Javadoc。
请注意，以 `#` 开头的 JDL Studio 指令在解析期间将被忽略。

另一种注释形式是以下注释：

```jdl
entity A {
  name String /** My super field */
  count Integer /** My other super field */
}
```

这里 A 的 name 将被注释为 `My super field`，count 被注释为 `My other super field`。

是的，逗号不是必需的，但明智的做法是使用它们，以免在代码中犯错。
**如果您想混合使用逗号和后续注释，请小心！**

```jdl
entity A {
  name String, /** My comment */
  count Integer
}
```
A 的 name 不会有注释，因为 count 会有。


## 字段类型和验证

每种字段类型都有自己的验证列表。以下是 JDL 中支持的类型：

|JDL 类型     |验证                                        |
|--------------|-------------------------------------------------|
|String        |required, minlength, maxlength, pattern, unique|
|Integer       |required, min, max, unique                      |
|Long          |required, min, max, unique                      |
|BigDecimal    |required, min, max, unique                      |
|Float         |required, min, max, unique                      |
|Double        |required, min, max, unique                      |
|Enum          |required, unique                                |
|Boolean       |required, unique                                |
|LocalDate     |required, unique                                |
|ZonedDateTime |required, unique                                |
|Instant       |required, unique                                |
|Duration      |required, unique                                |
|LocalTime     |required, unique                                |
|UUID          |required, unique                                |
|Blob          |required, minbytes, maxbytes, unique            |
|AnyBlob       |required, minbytes, maxbytes, unique            |
|ImageBlob     |required, minbytes, maxbytes, unique            |
|TextBlob      |required, unique                                |
