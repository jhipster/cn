## 语法

枚举声明如下：

```jdl
enum <enum name> {
  <ENUM KEY> [(<enum value>)]
}
```

  - 枚举条目值是必需的
    - 并且必须使用大写键
  - 枚举条目值是可选的，并且必须用圆括号包裹

---

## 示例

### 基本示例

```jdl
enum Country {
  BELGIUM,
  FRANCE,
  ITALY
}
```

其使用方式：

```jdl
enum Country {}

entity A {
  country Country
}
```

### 包含值

从 JHipster Core v6 开始，枚举值可以有显式值：

```jdl
enum Country {
  BELGIUM (Belgium),
  FRANCE (France),
  ITALY (Italy),
  CHINA ("中国")
}
```

### 注释

就像关系、实体和字段一样，可以对枚举进行注释，遵循相同的规则。

注释将由 JHipster 后续添加为 Javadoc 注释。JDL 拥有自己的注释类型：
  - // 一个被忽略的注释
  - /** 不被忽略的注释 */

因此，任何以 `//` 开头的内容都被认为是 JDL 的内部注释，不会被计为 Javadoc。
请注意，以 `#` 开头的 JDL Studio 指令在解析期间将被忽略。

```jdl
/** 此注释将被考虑 */
enum Country {
  // 但这个不会！
  FRANCE
}
```
